Структура архивной папки дипломного проекта «Сфера»

В данном архиве содержатся все материалы, необходимые для защиты выпускной квалификационной работы (ВКР):

01_PZ/
    - Пояснительная записка (ПЗ) в форматах DOCX и PDF.

02_Presentation/
    - Презентация для защиты дипломного проекта и раздаточные материалы.

03_Schemes/
    - Архитектурные схемы системы, схема базы данных (UML ERD), диаграммы процессов взаимодействия.

04_Code/
    - Полный исходный код проекта «Сфера» (архив Eventmate.zip).

05_DB_API/
    - Схема и дамп базы данных, описание API эндпоинтов, примеры запросов и ответов в JSON.

06_Testing/
    - Сценарии тестирования (E2E), результаты выполнения тестов бэкенда, логи сборки фронтенда.

07_UI_Docs_Economics/
    - Скриншоты пользовательского интерфейса, руководства пользователя и администратора, экономические расчеты стоимости проекта.

README.txt
    - Описание структуры архива и краткая инструкция по верификации запуска.

--------------------------------------------------------------------------------
КРАТКАЯ ИНСТРУКЦИЯ ПО ЗАПУСКУ И ВЕРИФИКАЦИИ

Для развертывания проекта в локальном окружении выполните следующие действия:

1. Откройте файл README.md в корневом каталоге кода для детальных инструкций.
2. Скопируйте шаблон настроек бэкенда:
   в папке backend/ скопируйте .env.example в .env и настройте переменные.
3. Скопируйте шаблон настроек фронтенда:
   в папке frontend/ скопируйте .env.example в .env.local.
4. Запустите бэкенд сервер:
   создайте python venv, установите pip зависимости (requirements.txt), примените миграции (manage.py migrate) и запустите сервер (manage.py runserver).
5. Запустите фронтенд:
   выполните npm install и запустите сервер разработки (npm run dev).
6. Запустите тесты бэкенда для верификации работоспособности кода (python manage.py test ...).
7. Проверьте основные сценарии по демонстрационному E2E-сценарию, описанному в README.md (включая AI-помощников генерации текста и QR-верификацию этапов работ).
